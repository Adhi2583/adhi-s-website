College Course Registration System

Java Servlets + JSP + JDBC + MySQL

How to run

About the project

A web application where students register, log in, view available courses, enroll in or drop courses, and update their profile. All data is stored in a MySQL database and accessed using JDBC.

Features

Student registration and login
View all courses with seats left
Enroll in a course
Drop a course
My Courses with total credits
Edit profile

SQL operations used

OperationWhere it is used
INSERTRegister student, enroll in course
SELECTLogin, course list, My Courses, profile
UPDATESeats left, drop course, edit profile

Technologies

Frontend
JSP, HTML, CSS
Backend
Java Servlets, JDBC
Database
MySQL
Server
Apache Tomcat 9

How to run

  1. Run database.sql in MySQL.
  2. Set your MySQL password in src/com/college/DBUtil.java.
  3. Add mysql-connector-j jar to WebContent/WEB-INF/lib.
  4. Import into Eclipse as a Dynamic Web Project and run on Tomcat 9.
  5. Open the URL below in your browser.
http://localhost:8080/course-registration/

Project structure

course-registration/
  database.sql
  src/com/college/   (DBUtil, Login, Register, Course, Enroll, Profile servlets)
  WebContent/        (index.jsp, register.jsp, courses.jsp, mycourses.jsp, profile.jsp, css/)
